## Prerequisites
Install the `atproto` python library:
```
pip install atproto
```

## Configuration

To use this script, you'll need to add a file called `bsky_random_sweep.appsettings.local.json` in the same folder as `bsky_random_sweep.py` with the following configuration:

```
{
  "bsky_handle": "<INSERT YOUR BSKY HANDLE HERE>",
  "bsky_app_password": "<INSERT YOUR APP PASSWORD HERE>",
  "batch_size": 10,
  "pds_host": "<INSERT YOUR PDS HOST HERE OR LEAVE AS EMPTY STRING>"
}
```

`bsky_handle` is your bluesky handle (with no @ symbol).

`bsky_app_password` can be generated by going to Bluesky's Settings > Privacy and Security tab. It should be in the format `xxxx-xxxx-xxxx-xxxx`.

`batch_size` is how many posts should be served when you run.

`pds_host` is optional, leaving it empty will default to Bluesky's PDS Host. If you don't know what that means, then you probably are on Bluesky's PDS host :3. For example, I use `https://northsky.social`.

## Running the script
In bash, run `python bsky_random_sweep.py`.
